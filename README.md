# Morgen-Briefing

Privater Podcast-Feed. Die tägliche Folge erstellt eine geplante Claude-Aufgabe:
Skript in `folgen/JJJJ-MM-TT.md`, dann `python3 build.py --script ... --title ...`,
danach Commit und Push. GitHub Pages liefert `feed.xml` und `audio/` aus.

Feed: https://2anton1.github.io/morgen-briefing/feed.xml
